# GLaDOS

GLaDOS is an open-source voice assistant inspired by the AI character from *Portal*. The project combines speech recognition, text-to-speech, conversational AI, and audio processing to create an interactive voice-based assistant.

## Features

- Voice-based interaction
- Speech-to-text and text-to-speech support
- Conversational AI integration
- Audio input/output processing
- WebSocket-based audio communication
- Modular Python architecture

## Technologies

- Python
- WebSockets
- Speech Recognition
- Text-to-Speech
- Large Language Models
- Audio Processing
